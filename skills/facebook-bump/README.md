# Facebook 群组顶帖技能（整理版导出）

供 Codex 或其他代理安装使用。本目录是按已证实历史流程整理的可移植技能，不是技能库里已有原版文件的拷贝。把本包装入 Codex 不等于授权执行 Facebook 操作，也不等于恢复任何例行。

## 安装

1. 解压后应得到目录 `facebook-bump/`，内含 `SKILL.md` 和本 `README.md`。
2. 将整个 `facebook-bump/` 目录放到 Codex 读取技能的位置，例如项目内 `.agents/skills/facebook-bump/`，或以你当前 Codex 技能配置为准。
3. 确认 Codex 能读到 `SKILL.md` 的 frontmatter（`name`、`description`）和正文。
4. 把正文里的抽象页面操作（打开搜索页、滚动、切换「最新」、读取可见文本和计数、在批准后点击赞或提交评论）映射到 Codex 实际具备的浏览器工具。环境里没有可用的页面操作能力就停止，不要改写流程去绕过登录或安全检查。
5. 不要把本文件改回对某一家代理专有工具名的依赖；也不要在技能里写入账号、密码、私人路径或某一次批次清单。

## 使用前

- 必须有用户对本轮搜帖或顶帖的明确委托，以及群/帖范围授权。
- 先配置 Like / 评论阈值；未配置时只记录计数，不自动判定达标。
- 评论必须逐条预览批准后再提交；点赞也需授权。
- 遇到 checkpoint 或账户警告立即停止。

## 来源说明

整理时对照了站外 SOP 中的顶帖步骤、本地历史搜帖记录里的精确码搜索与计数注意事项，以及用户已确认的审批和安全边界。技能目录中未找到可原样导出的顶帖 `SKILL.md`。
