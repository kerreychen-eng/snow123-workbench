## 删减与冲突取舍

- 三个模块均为可选；目标明确时直接选对应模块，不强制每次全跑，也不每次先问。模块 B 合并搜码反查与空档有界入口研究（后者单轮最多 3 个）；模块 C 只补 CA、UK、FR、JP、IT、MX、ES 本地空白，约 5 分钟小轮，复用码/域名去重，不重复每日搜码。
- 不含投稿、注册执行、发信/私信/顶帖、测码下单、海报制作、品牌日报监控、外链内容分发。合格渠道只形成待交接材料。
- 历史日期补丁合成唯一规则：安全警告立即停；普通超时只允许合理一次；排除名单、表路径、种子和频率放到运行配置，不把个人目标写进通用正文。
- 删除硬编码个人身份、私人邮箱/ID、浏览器与代理路径、内部子任务或专有工具名、凭据与秘密环境变量、工作台私有路径。
- 安全取最新从严：废弃旧版「限流重试一次」。加载失败的一次重试只适用于普通网络超时。加载失败不得判 removed。阻塞未解除且无新输入则记录断点退出，不重复离线扫描；未经联网完成的进度不能记为已联网发现。
- 不以旧队列策略「只申请加入私密群」为准；现行规则是私密群不申请加入。
- 发现合格线以技能正文第 5.1 节为准。互动检查触发阈值不等于已证实真实粉丝。站外 SOP 里「约 50 个码、赞/评平均各以 5 为线」的完善资源口径与本次搜索无关，未纳入核心正文。
- 关注/点赞是主页级、须本轮授权、每轮 ≤ 20 是上限不是目标。
- 不把无变化重扫或无限排队写进技能。旧记录合并必须有同一稳定 ID 或明确官方归属，不凭同名，不删除历史。
